# Exam Monthly · 시험 먼슬리 플래너

시험 계획을 먼슬리 캘린더에 정리하는 웹사이트입니다.
Google 계정으로 로그인하면 아이패드 · 노트북 · 폰에서 같은 플래너가 실시간으로 동기화됩니다.

## 기능

- **먼슬리 캘린더**: 오른쪽 위 `‹ 2026 ›`로 연도, 1~12로 월 이동 · `오늘로`
- **TITLE**: 달마다 제목을 따로 저장
- **시험일 · D-day**: 시험을 여러 개 등록하면 각 날짜에 가장 가까운 다음 시험의 D-day 표시
- **할 일**
  - 칸 오른쪽 위 `+`로 추가, 칩을 누르면 수정 · 날짜 변경 · 삭제
  - 칩 앞 동그라미를 누르면 완료 (색이 짙어짐)
  - 칩을 드래그해서 다른 날짜로 이동 (터치는 길게 눌러서 끌기)
  - 한 칸에 7줄 이상 보이고, 넘치면 칸 안에서 스크롤
- **카테고리**: Category1(과목) → Category2(그 과목의 문제집). 과목을 골라야 그 과목의 문제집만 보임
- **테마**
  - 캘린더 스타일 5종: 심플 · 손글씨 · 그리드 · 빈티지 페이퍼 · 나이트
  - 과목 색상 13종: 봄 · 여름 · 가을 · 겨울 · 모카 · 석양 · 말차딸기 · 체리라떼 · 미드나잇 · 딥씨 · 라벤더필드 · 빈티지노트 · 블루아워
  - 글씨체 5종: 나눔명조(기본) · 고운바탕 · 고운돋움 · 개구 · 나눔펜
  - 나이트모드 버튼 (팝업까지 어둡게)
- **계정**: Google 로그인 · 동기화 상태 · 로그인된 기기 목록 · 백업 파일 저장/불러오기

## 바로 실행해 보기

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 동작하지 않고, 간단한 웹서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

Firebase를 설정하기 전에는 로그인 없이 **이 기기(브라우저)에만 저장**하는 모드로 동작합니다.
이 모드에서 쓰던 데이터는 나중에 처음 Google 로그인할 때 계정으로 그대로 옮겨집니다.

## Firebase 설정 (Google 로그인 + 동기화)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 **프로젝트 추가**
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google** 사용 설정
3. **빌드 → Firestore Database → 데이터베이스 만들기** (위치는 `asia-northeast3 (서울)` 추천, 프로덕션 모드)
4. Firestore의 **규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 **게시**
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹 앱 추가(`</>`)** 후 나오는 `firebaseConfig` 값을
   [`js/config.js`](js/config.js)에 붙여넣기
6. **Authentication → 설정 → 승인된 도메인**에 사이트 주소 추가
   (예: `아이디.github.io`. `localhost`는 기본으로 들어 있음)

`firebaseConfig`의 `apiKey`는 비밀번호가 아니라 프로젝트를 가리키는 식별자라서 공개 저장소에 올라가도 괜찮습니다.
데이터는 4번의 보안 규칙으로 보호됩니다 (로그인한 본인만 자기 문서를 읽고 쓸 수 있음).

## GitHub Pages로 배포

1. 이 저장소의 **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save
3. 잠시 후 `https://<아이디>.github.io/monthly/`에서 열림
4. 이 주소의 도메인(`<아이디>.github.io`)을 Firebase 승인된 도메인에 추가

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 뼈대 · 글꼴 불러오기 |
| `css/style.css` | 화면 디자인 (스타일 · 나이트모드 · 칸 크기) |
| `js/app.js` | 화면 그리기, 버튼 동작, 드래그, 동기화 흐름 |
| `js/data.js` | 테마 13종 · 스타일 5종 · 글씨체 5종 · 공휴일 |
| `js/store.js` | 데이터 형식, 이 기기 저장, 동기화용 비교/합치기 |
| `js/cloud.js` | Firebase 로그인 · Firestore 읽기/쓰기 |
| `js/config.js` | Firebase 설정값 (직접 채우기) |
| `firestore.rules` | Firestore 보안 규칙 |

## 동기화 방식 메모

- 사용자마다 Firestore 문서 하나(`users/{uid}`)에 할 일 · 과목 · 문제집 · 시험 · 제목 · 설정을 항목별로 저장합니다.
- 바뀐 항목만 보내기 때문에, 두 기기에서 동시에 서로 다른 항목을 고쳐도 둘 다 반영됩니다.
  같은 항목을 동시에 고치면 나중에 저장된 쪽이 남습니다.
- 인터넷이 끊겨도 이 기기에 먼저 저장되고, 다시 연결되면 서버와 합쳐집니다.
- Firestore 문서 하나의 최대 크기는 1MB라서, 할 일은 대략 5천 개 정도까지 담을 수 있습니다.
- 공휴일 중 설날 · 추석 · 부처님오신날 · 대체공휴일은 2025~2027년만 들어 있습니다 (`js/data.js`의 `HOLIDAY_TABLE`에 추가 가능).
